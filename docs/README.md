Рабочая реализация находится в `src/`: HTTP и CLI, сценарии конвейера и оценки,
бизнес-правила, адаптеры и сборка зависимостей разделены по слоям.
Внешний `local-dev/run.sh` запускает новые точки входа напрямую; пакет `app` удалён.
Границы импортов проверяет `tests/test_architecture.py`.

Неочевидное решение записываем в подходящий документ: что решили, почему и
как это влияет на дальнейшие изменения. Ссылку на раздел добавляем в
`AGENTS.md`, если без этого решения легко нарушить архитектуру или поведение.
Отдельный документ создаём, когда у решения появляется самостоятельная тема.

Описание запуска и происхождения кода остаётся в [README проекта](../README.md).
