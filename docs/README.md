# Документация speech-backend

Правила для работы с проектом находятся в [AGENTS.md](../AGENTS.md).

| Документ | Когда читать |
|---|---|
| [Архитектура](architecture.md) | При размещении кода, выборе зависимостей, DTO и интерфейсов |
| [Границы сервисов](service-boundaries.md) | При разделении бэкенда и воркера и выборе контрактов между проектами |
| [Разработка](development.md) | При написании кода, докстрингов и запуске проверок |
| [Контекст проекта](project-context.md) | Перед переносом сценария или работой с базой и контрактами |

Рабочая реализация находится в `src/`: HTTP и CLI, сценарии конвейера и оценки,
бизнес-правила, адаптеры и сборка зависимостей разделены по слоям. В `app/`
остались только совместимые точки запуска для внешнего `local-dev/run.sh`.
Границы импортов проверяет `tests/test_architecture.py`.

Неочевидное решение записываем в подходящий документ: что решили, почему и
как это влияет на дальнейшие изменения. Ссылку на раздел добавляем в
`AGENTS.md`, если без этого решения легко нарушить архитектуру или поведение.
Отдельный документ создаём, когда у решения появляется самостоятельная тема.

Описание запуска и происхождения кода остаётся в [README проекта](../README.md).
